# Accessibility of the kit's components (WCAG 2.1 AA)

From the Design plugin's `accessibility-review`, as acceptance criteria per component. Automated scans find about a
third of the problems; the keyboard pass and a screen reader find the rest.

Common: contrast 4.5:1 text and 3:1 borders and focus (the tokens are checked by `theme.test.ts`); `:focus-visible`
on every control; targets ≥ 44 px on a coarse pointer (`--touch`); nothing conveyed by color alone (a badge has
text; a light has its word); `prefers-reduced-motion` honoured.

| Component | Must |
| --- | --- |
| `Menu` | trigger `aria-haspopup="menu"` + `aria-expanded`; list `role="menu"`, items `role="menuitem"`, roving focus with ↑ ↓ Home End, Esc closes and returns focus to the trigger, Tab leaves |
| `Tooltip` | shows on hover and on focus; `role="tooltip"` linked by `aria-describedby`; never the only name of a control (use `aria-label` for icon buttons) |
| `Dialog` / `ConfirmDialog` | native `<dialog>` with `showModal` (focus trapped, page inert), `aria-label` = title, Esc closes, focus starts on the safe button when `danger`, Enter confirms |
| `Drawer` | `role="dialog"` with `aria-labelledby`, not modal on desktop (the grid keeps working), `aria-modal` on phones; Esc closes; the first field takes focus; the resize handle is a focusable `separator` with arrow keys |
| `RecordPicker` | `role="combobox"` + `aria-expanded` + `aria-controls` + `aria-activedescendant`; options `role="option"` with `aria-selected`; ↑ ↓ ⏎ Esc; Backspace on a chosen value clears it; results announced through the listbox |
| `DateInput` / `Calendar` | the text box is the labelled control (tests fill it with ISO); the calendar is `role="grid"` with roving focus, arrows move a day or week, PgUp/PgDn a month, Enter picks, `aria-current="date"` on today, `aria-selected` on the value |
| Grid | `<table>` with `scope="col"` headers and `aria-sort`; rows focusable one at a time (roving `tabIndex`), ↑ ↓ Home End PgUp PgDn, ⏎ opens, Space marks, action keys run `rowActions`; header drag also by Alt ← →; the ⋯ menu reachable by Tab; resize handle `role="separator"` |
| `Breadcrumbs` | `<nav aria-label>`, the current tramo `aria-current="page"`, the copy-link button named |
| `Toast` | `aria-live="polite"` region, `role="status"`, closes on its own and by a button; an action inside is a real button |
| Keys drawn beside an action | `KeyHint`, the keys in a confirmation, a menu item or a palette option are `aria-hidden`: the button keeps its own name («Guardar»); the `?` dialog lists every key with its description |
| `Badge` / `Light` | text always beside the color; the dot is `aria-hidden` |
| Forms | `<label htmlFor>` on every control (the tests find fields by label), `aria-required` not the attribute (the kit validates), `aria-invalid` + `aria-describedby` to the error, `role="alert"` on the error |
